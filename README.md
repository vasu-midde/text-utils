# TextUtils

A small React app for quick text clean-up: change case, remove extra spaces, copy, and see live word and character counts.

**Live demo: https://vasu-midde.github.io/text-utils/**

## Features

- Convert to UPPERCASE or lowercase
- Remove extra spaces
- Copy to clipboard and clear text
- Live summary: word count, character count and estimated reading time
- Preview pane
- About page (React Router)

## Run locally

```bash
npm install
npm start
```

## Deploy

```bash
npm run deploy   # builds and publishes to GitHub Pages
```

## Tech

React 18 · React Router (HashRouter for GitHub Pages) · Bootstrap 5 · JavaScript
